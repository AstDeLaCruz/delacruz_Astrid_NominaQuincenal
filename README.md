##  Descripción

Aplicación de escritorio que calcula el pago quincenal de empleados. El usuario escribe el nombre, elige el contrato (Fijo o Temporal) y el cargo, ingresa las horas trabajadas e indica si recibe incentivo de transporte. El sistema calcula el pago neto, lo agrega a una lista y muestra un resumen con los totales.

##  Funcionalidades

* Registrar empleado y calcular su pago neto.
* Horas extra (desde la hora 89) con 35 % adicional.
* Incentivo de transporte de RD$ 1,500.
* Deducciones AFP 2.87 % y SFS 3.04 % solo en contrato Fijo.
* Mostrar resumen con cantidad de empleados y totales de bruto, deducciones y neto.
* Limpiar el formulario y salir de la aplicación.
